# 13 — Future Expansion

## v1 rule

Hard-focus on Italian → Hungarian.

Keep language pair represented as data, but do not build generic multilingual UI before the core loop works.

## Future source modes

Potential later inputs:

- image/OCR text;
- browser-tab audio with explicit user sharing where browser/platform rules permit;
- imported user-owned recordings;
- camera text capture;
- user-authored notes/documents with larger limits and appropriate policy.

## Future languages

Potential learning languages:

- English;
- German;
- French;
- Spanish;
- others based on demand and provider quality.

UI language and learning pair should remain separate concepts.

## Future learning features

- pronunciation scoring;
- shadowing timeline;
- spaced repetition;
- personalised weak-point detection;
- recurring phrase review;
- contextual conversation generated from saved phrases.

## Copyright-sensitive future features

Any feature that fetches third-party protected content, increases source length, creates public sharing, or performs bulk ingestion requires a fresh legal/product review before implementation.
