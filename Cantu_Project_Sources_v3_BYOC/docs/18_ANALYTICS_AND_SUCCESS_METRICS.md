# 18 — Analytics & Success Metrics

## North-star behaviour

A learner brings real Italian they encountered and reaches a moment of genuine understanding quickly enough to want to analyse or practise another item.

## Funnel

Privacy-safe events:

1. landing viewed;
2. input mode selected;
3. microphone permission outcome (Listen only);
4. audio file opened / text entered;
5. audio range selected;
6. source submitted;
7. transcript returned;
8. transcript confirmed vs edited;
9. learning result ready;
10. first chunk opened;
11. recall started;
12. recall completed;
13. phrase saved;
14. second learning session within 7 days.

## Core metrics

- input-start rate;
- input-completion rate by mode;
- median audio selection duration;
- transcript edit rate;
- STT success rate;
- median time input → verified source;
- median time verified source → learning result;
- learning-result completion rate;
- phrase-save rate;
- recall completion/score;
- second-session rate;
- weekly returning learner rate.

## Learning signal

After completion:

> **Most már érted ezt a részt?**

Options:

- `Igen`
- `Nagyjából`
- `Még nem`

Optional second signal:

> **El tudnád használni valamelyik kifejezést?**

## Privacy

Never put into generic analytics:

- raw audio;
- complete source text;
- transcript body;
- translated body;
- sensitive personal content.

Analytics should receive lengths, states, timings and anonymous/appropriate identifiers only.
