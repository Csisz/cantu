# 18 — Analytics & Success Metrics

## North-star behavior

A user brings a real song and reaches meaningful understanding quickly enough to want another song or a Deep Dive.

## Funnel

Track privacy-safe events:

1. landing viewed;
2. Listen clicked / Upload clicked;
3. microphone permission outcome;
4. recognition success/no-match;
5. candidate confirmed/rejected;
6. lyrics available/unavailable;
7. lesson ready;
8. Quick Understand started;
9. Quick Understand completed;
10. Deep Dive started;
11. second song started within 7 days.

## Key product metrics

- recognition confirmation rate;
- median time from Listen click → confirmed song;
- median time confirmed song → Song Snapshot;
- lesson generation success rate;
- Quick Understand completion rate;
- quiz completion/score distribution;
- Deep Dive conversion;
- second-song rate;
- weekly returning learner rate.

## Learning signal

Add a tiny post-lesson self-check:

> “Most már érted, miről szól a dal?”

Options: `Igen` / `Nagyjából` / `Még nem`.

This directly measures the core promise better than raw page views.

## Privacy

Never send microphone audio or lyrics text into generic analytics event payloads.
