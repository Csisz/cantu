# 02 — Learning Experience

## Principle

Do not begin by showing a wall of lyrics. Begin with meaning, then reveal language in memorable chunks.

## Primary journey

### 1. Home

Two equal entry actions:

- **🎧 Hallgasd meg a dalt** — Cantu listens for ~8–15 seconds.
- **⬆️ Feltöltöm a zenét** — local audio.

Secondary:

- “Nem működik? Keresés cím vagy előadó alapján.”

### 2. Recognition

Animated listening state with a waveform and robot feedback:

- “Figyelek…”
- “Megpróbálom felismerni…”

Never fake certainty.

### 3. Confirmation

Display a clear candidate card:

- cover art;
- title;
- artist;
- album when available;
- optional Spotify/Apple link badge;
- `Igen, ez az` primary button;
- `Nem ez` secondary button.

No lyrics/LLM generation before confirmation.

### 4. Song Snapshot

First educational reward should arrive quickly:

- **Miről szól?** 2–4 sentence Hungarian summary;
- mood/theme chips;
- “3 kifejezés, amit már az első hallgatásnál elcsíphetsz”.

### 5. Quick Understand

Recommended sequence:

1. chorus meaning;
2. key phrase cards;
3. important lines;
4. mini grammar insight;
5. listening/meaning match;
6. 5-question quiz.

### 6. Completion

Message:

> **Most már érted a dal lényegét.**

Show what the learner gained:

- learned expressions;
- understood sections;
- quiz score.

Then offer:

- **Folytatom a teljes dal megértését** → Deep Dive;
- **Új dalt tanulok**.

## Deep Dive progression

Prefer section-by-section unlock:

`chorus → verse 1 → verse 2 / bridge → remaining lines → full understanding`

Each section can contain:

- original permitted text/snippet;
- Hungarian explanation;
- literal meaning only when pedagogically useful;
- idiom/culture note;
- pronunciation hint;
- recognition exercise.

## Learning design guardrails

- teach useful chunks, not isolated dictionary dumps;
- prioritize repeated chorus language;
- label slang/poetic language so learners do not overgeneralize it;
- avoid claiming one translation is the only possible meaning;
- explain omitted subjects, contractions and poetic word order;
- keep grammar notes short and anchored in the song;
- use Hungarian natural-language explanations, not textbook jargon where avoidable.
