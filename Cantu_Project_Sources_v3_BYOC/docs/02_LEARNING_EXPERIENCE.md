# 02 — Learning Experience

## Principle

Do not begin with grammar or a wall of transcription. Begin with **meaning**, then reveal useful structure, then require a tiny active response.

## Primary journey

### 1. Home / Input Studio

Three clear actions:

- **🎧 Hallgasd** — record a short excerpt.
- **🎵 Hangfájl** — open local audio and select the part you want to understand.
- **📝 Szöveg** — paste/type a short Italian passage.

Supporting message:

> Értsd meg az olaszt, amivel tényleg találkozol.

### 2A. Listen

- explicit record button;
- browser permission only after user action;
- clear recording indicator;
- visible elapsed/remaining time;
- hard stop at configured maximum;
- cancel always available.

### 2B. Audio file

- local file chooser;
- waveform;
- draggable selection;
- selection duration;
- maximum 30 seconds;
- local preview playback;
- `Ezt a részt értsük meg` action.

The complete file should not be uploaded just to draw the waveform.

### 2C. Text

- textarea;
- character count;
- 2,000-character initial limit;
- `Ezt értsük meg` action.

### 3. Verify

For audio:

**Ezt hallottam:**

Show STT transcript with confidence/uncertainty markers where available.

Actions:

- `Igen, pontos`
- `Javítom`
- `Újra próbálom`

For text:

**Ezt fogjuk elemezni:**

Show exactly the submitted text before expensive AI generation.

### 4. Understand

First educational reward:

**Mit jelent?**

- 1–3 natural Hungarian sentences;
- preserve tone and intent;
- avoid word-for-word translation unless it helps.

Optional:

**Szó szerint hogy áll össze?**

Only when literal structure clarifies the Italian.

### 5. Notice

Show 3–6 high-value chunks.

Examples of chunk types:

- phrase;
- verb + preposition;
- fixed expression;
- pronoun construction;
- idiom;
- conversational filler with real function.

Each item should answer:

- what does it mean here?
- when would I use it?
- is it neutral, formal, colloquial, slang or poetic?

### 6. One contextual language insight

Use a compact card such as:

**Miért így mondják?**

Teach only what helps decode this input.

Avoid generic textbook lectures.

### 7. Say

Prompt a useful phrase for repetition/shadowing.

Early MVP may offer playback + user self-check. Automated scoring comes later.

### 8. Recall

2–4 tiny questions:

- phrase meaning;
- choose the natural interpretation;
- fill the useful chunk;
- choose an appropriate situation.

### 9. Save

Offer:

- save useful phrases;
- save learning result;
- do not force saving the complete source content.

## Unique learning mechanics

### Meaning Map

Separate:

- natural meaning;
- literal structure;
- tone/register.

### Chunk Lens

Teach reusable multi-word language, not isolated dictionary entries.

### Why Here?

Explain grammar only in relation to this exact context.

### Transfer Challenge

Generate one new, original example using the same pattern so the learner transfers knowledge beyond the source.

### Confidence Lens

If transcription/interpretation is uncertain, say so. The learner can correct the source before teaching continues.

## Completion message

> **Most már érted — és van belőle valami, amit te is tudsz használni.**
