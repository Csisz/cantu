# Cantu Source Pack v3 — Changelog

## Product pivot

Cantu moves from “learn Italian through song lyrics” to **“learn Italian from the real audio and text you encounter.”**

## Added

- Bring Your Own Content model.
- First-class text input.
- Local full-audio handling and waveform selection.
- Maximum 30-second selected audio processing window for MVP.
- Transcript verification/edit step before learning generation.
- Unified learning loop: Understand → Notice → Say → Recall.
- Legal-by-design constraints and launch checklist.
- Source-light persistence strategy.
- Anti-reconstruction guardrails for copyrighted works.
- New generalized data model direction.
- New Milestone 2 target and Codex implementation prompt.

## Removed from core product

- music-recognition-first positioning;
- global song identity as the main product input;
- full lyrics provider dependency;
- lyrics catalogue architecture as a critical path;
- “learn any popular song” commercial promise.

## Still possible as user input

A user may privately process a short excerpt that happens to come from music or another copyrighted source, subject to product limits, user rights/terms, privacy controls, and legal review. Cantu does not fetch the underlying protected work for them.
