# Cantu Source Pack v2 — Changelog

## Added

- Shazam-like **Listen & identify** flow.
- Browser microphone capture and recognition state model.
- User validation step before lyrics/AI processing.
- Provider abstraction for music recognition.
- AudD as recommended first web spike; ACRCloud as alternative evaluation path.
- ShazamKit positioned as a future native-app option rather than a web dependency.
- Spotify/YouTube link-resolution concept without protected-audio downloading.
- Recognition privacy and cost guardrails.
- Recognition-specific data model, endpoints and acceptance tests.
- New first-conversation starter prompt for generating Milestone 0 Codex CLI instructions.

## Fixed

The previous generated archive referenced documentation files in its manifest but did not actually contain the `docs/` and `prompts/` contents. This pack includes all referenced files physically in the archive.
