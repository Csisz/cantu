# 15 — Current Technical References — 2026-08-25

These references were checked while preparing the v2 source pack. Re-check vendor terms/pricing before production commitment.

## Music recognition

### AudD

- Docs: https://docs.audd.io/
- Node SDK: https://docs.audd.io/sdks/node/

Relevant capabilities documented:

- standard Shazam-like recognition from short audio;
- upload by URL or multipart file;
- browser/Node Blob/File support in SDK;
- title, artist, album, timecode;
- optional Spotify and Apple Music metadata.

### ACRCloud

- Recognition tutorial: https://docs.acrcloud.com/get-started/tutorials/recognize-music

Relevant capability documented:

- identify music using microphone or line-in sources against ACRCloud music databases.

### Apple ShazamKit

- Overview: https://developer.apple.com/shazamkit/
- Framework docs: https://developer.apple.com/documentation/ShazamKit

Relevant capability documented:

- acoustic-signature music matching against Shazam catalog/custom catalogs;
- native Apple platforms and Android SDK;
- useful future native Cantu path, not assumed for browser MVP.
