# 00 — Product Brief

## Product

**Cantu** is an audio-first and text-first language-learning web application. A learner brings a short piece of Italian they encountered in real life; Cantu helps them verify it, understand it in Hungarian, notice useful language, and actively practise it.

### Initial language pair

- Learning language: **Italian**
- Explanation/UI language: **Hungarian**

## Problem

People encounter useful foreign-language material constantly — conversations, videos, podcasts, songs, messages, captions, menus and short texts — but ordinary translation tools usually stop at “what does this mean?”. Traditional learning apps often teach generic material disconnected from the learner's real context.

Cantu turns a learner's **own encountered content** into a short learning moment.

## Promise

> **Hallgasd. Olvasd. Értsd meg. Mondd ki.**

Cantu should take the learner from:

> “I heard/read this but I do not really understand it.”

into:

> “I understand what it means, I noticed the useful phrase, and I can recognise or use it again.”

## Primary jobs to be done

1. **Understand this short Italian audio.**
2. **Understand this text without getting only a literal translation.**
3. **Show me the few words/chunks worth learning.**
4. **Explain why Italians say it this way.**
5. **Help me say or recall it myself.**
6. **Remember useful language without forcing me to save the entire source.**

## Input modes

### Listen

Explicitly record a short segment with the microphone.

### Audio file

Open a local audio file, inspect its waveform locally, select a maximum 30-second excerpt, and process only that excerpt.

### Text

Paste/type a short Italian passage.

## The Cantu learning loop

`Bring → Verify → Understand → Notice → Say → Recall → Save`

### Bring

The learner chooses the exact short source they care about.

### Verify

For speech, Cantu shows the transcript first. The user can correct it before learning generation.

### Understand

Natural Hungarian meaning comes first.

### Notice

Cantu selects a small number of reusable chunks, idioms, register cues and contextual grammar wins.

### Say

The learner hears/repeats or prepares to repeat the most useful phrase.

### Recall

A tiny retrieval task checks whether meaning was actually learned.

### Save

The learner may save useful phrases and learning results. The original source does not need to be retained permanently.

## Differentiation

Cantu is not primarily:

- a translation box;
- a chatbot;
- a transcription service;
- a lyrics viewer;
- a flashcard generator.

Its value is **contextual pedagogical compression**: take authentic user-selected language and identify the smallest set of explanations and actions that convert it into learning.

## Legal/product positioning

Cantu does not promise access to copyrighted works. It processes material brought by the user in a private workflow. The service should minimise source retention and avoid public redistribution, cataloguing or reconstruction of protected works.

No product copy should imply that a numeric excerpt duration automatically creates copyright permission.
